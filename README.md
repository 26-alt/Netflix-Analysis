## 📖 Overview

This project focuses on analyzing the Netflix dataset to understand content trends, including movies and TV shows, release patterns, countries, genres, and other insights.

The project includes data cleaning, exploratory data analysis, visualization using Python libraries, and an interactive dashboard created using Power BI.

## ✨ Features

- Data cleaning and preprocessing using Pandas
- Handling missing values and duplicate records
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib and Seaborn
- Interactive dashboard creation using Power BI
- Analysis of Netflix content trends

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
